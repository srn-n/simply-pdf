# Change records (no version bump)

Changes that don't bump the app version (docs, tooling, CI, tests only) each get a file here, named `YYYY-MM-DD-<topic>.md`.

Each record covers:
- what changed and why
- how it was checked
- the files touched
- whether it affects the website, the Android app, or both

App changes that bump the version go in `docs/releases/<version>.md` instead.
